# 404BDF Creative Landing Page

A high-end, ultra-creative landing page designed to serve as the gateway for the **404: Bad Design Found** project. This page is built with modern aesthetics focusing on glassmorphism, advanced animations, and high-impact visual storytelling.

## ✨ Visual Highlights

- **Glitch Preloader**: A professional SVG glitch animation that sets the "Bad Design" mood upon entry.
- **Hero Parallax**: An interactive hero section with floating design elements (Z-Index Hell, Color Chaos) that respond to mouse movements.
- **Vertical Timeline**: The "Arena Workflow" is presented as a sleek, alternating vertical timeline with glowing indicators.
- **Glassmorphism UI**: All sections use backdrop-blur and semi-transparent borders for a premium, futuristic look.
- **Reveal-on-Scroll**: Sections fade and slide into view as the user scrolls, powered by AOS (Animate On Scroll).
- **Custom Cursor**: A bespoke cursor and follower system that enhances the interactive feel of the site.

## 🛠️ Technology Stack

- **Structure**: Semantic HTML5.
- **Styling**: Vanilla CSS3 with custom variables and @keyframes.
- **Interactions**: Vanilla JavaScript (ES6+).
- **External Libraries**:
  - [AOS](https://michalsnik.github.io/aos/) (Animations)
  - [Font Awesome](https://fontawesome.com/) (Icons)
  - [Google Fonts](https://fonts.google.com/) (Outfit & Inter)
